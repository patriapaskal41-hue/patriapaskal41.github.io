JavaScript dan Fungsi Dasarnya

Pelajari dasar-dasar JavaScript untuk membuat website menjadi lebih interaktif dan dinamis.

Beranda Artikel Kategori

1. Apa Itu JavaScript?

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman website menjadi lebih interaktif.

Jika HTML digunakan untuk membuat struktur website dan CSS digunakan untuk mengatur tampilannya, JavaScript digunakan untuk memberikan perilaku atau aksi pada website.

Contoh:

console.log("Halo, Patria!");

Kode tersebut digunakan untuk menampilkan teks "Halo, Patria!" pada console browser.

2. Fungsi JavaScript dalam Website

JavaScript dapat digunakan untuk melakukan berbagai hal pada sebuah website.

  • Menampilkan pesan.
  • Mengubah teks pada halaman.
  • Mengubah tampilan elemen.
  • Membuat tombol menjadi interaktif.
  • Membuat validasi form.
  • Membuat animasi sederhana.
  • Mengolah data.

3. Cara Menambahkan JavaScript ke HTML

JavaScript dapat ditulis langsung di dalam file HTML menggunakan tag <script>.

Contoh:

<script>
    alert("Halo, Patria!");
</script>

Ketika halaman dibuka, JavaScript tersebut akan menjalankan perintah alert().

4. JavaScript Eksternal

Untuk project yang lebih rapi, JavaScript biasanya dipisahkan ke file sendiri dengan ekstensi .js.

Misalnya kita memiliki file: 

index.html
style.css
script.js

Kemudian file JavaScript dapat dihubungkan ke HTML menggunakan: 

<script src="script.js"></script>

Cara ini membuat kode HTML, CSS, dan JavaScript lebih terorganisir.

5. Variabel

Variabel digunakan untuk menyimpan data yang dapat digunakan oleh program.

Dalam JavaScript kita dapat menggunakan let dan const.

Contoh let:

let nama = "Patria";

console.log(nama);

Variabel nama menyimpan data berupa teks "Patria".

Contoh const:

const umur = 18;

console.log(umur);

const digunakan untuk nilai yang tidak ingin diubah setelah dibuat.

6. Tipe Data

Tipe data menunjukkan jenis data yang digunakan oleh program.

String

let nama = "Patria";

String digunakan untuk menyimpan teks.

Number

let umur = 18;

Number digunakan untuk menyimpan angka.

Boolean

let belajar = true;

Boolean memiliki dua nilai utama, yaitu true dan false.

7. Operator

Operator digunakan untuk melakukan operasi pada data.

Contoh operasi matematika:

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Operator tersebut digunakan untuk penjumlahan, pengurangan, perkalian, dan pembagian.

8. Percabangan if

Percabangan digunakan ketika program perlu mengambil keputusan berdasarkan suatu kondisi.

Contoh:

let umur = 18;

if (umur >= 17) {
    console.log("Sudah cukup umur");
}

Program akan menjalankan kode di dalam if jika kondisi tersebut bernilai benar.

9. Perulangan

Perulangan digunakan untuk menjalankan kode beberapa kali.

Contoh for:

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Kode tersebut akan menampilkan angka dari 1 sampai 5 pada console.

10. Function

Function atau fungsi adalah kumpulan kode yang dapat digunakan kembali untuk melakukan tugas tertentu.

Contoh:

function sapa() {
    console.log("Halo, Patria!");
}

sapa();

Function sapa() dapat dipanggil ketika kita ingin menjalankan kode yang ada di dalamnya.

11. JavaScript dan Tombol HTML

Salah satu penggunaan JavaScript yang sangat umum adalah membuat tombol HTML menjadi interaktif.

HTML:

<button onclick="sapa()">
    Klik Saya
</button>

JavaScript:

function sapa() {
    alert("Halo! Selamat belajar coding.");
}

Ketika tombol diklik, JavaScript akan menjalankan function sapa().

12. Mengubah Isi HTML dengan JavaScript

JavaScript juga dapat digunakan untuk mengubah isi elemen HTML.

HTML:

<h2 id="judul">Teks Lama</h2>

JavaScript:

document.getElementById("judul").textContent =
    "Teks Baru";

JavaScript mencari elemen dengan id judul, kemudian mengubah teksnya.

13. Contoh Project Sederhana

Setelah memahami dasar JavaScript, kamu bisa mencoba membuat project sederhana.

HTML:

<h2 id="angka">0</h2>

<button onclick="tambah()">
    Tambah
</button>

JavaScript:

let angka = 0;

function tambah() {
    angka++;

    document.getElementById("angka").textContent = angka;
}

Setiap tombol ditekan, nilai angka akan bertambah satu.

14. Kesalahan yang Sering Dilakukan Pemula

Saat belajar JavaScript, beberapa kesalahan berikut cukup sering terjadi:

  • Terlalu banyak menghafal kode.
  • Hanya melakukan copy-paste.
  • Tidak membaca pesan error.
  • Belajar terlalu banyak materi sekaligus.
  • Tidak pernah membuat project sendiri.

Jangan takut melakukan kesalahan. Error merupakan bagian dari proses belajar programming.

Kesimpulan

JavaScript adalah bahasa pemrograman yang sangat penting dalam pengembangan website modern. JavaScript memungkinkan sebuah halaman website menjadi lebih interaktif dan dinamis.

Sebagai pemula, kamu tidak perlu langsung mempelajari semuanya. Mulailah dari variabel, tipe data, operator, percabangan, perulangan, function, dan manipulasi HTML.

Setelah memahami dasar tersebut, lanjutkan dengan membuat project kecil agar kemampuanmu semakin berkembang.
