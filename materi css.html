1. Apa Itu CSS?

CSS adalah singkatan dari Cascading Style Sheets. CSS digunakan untuk mengatur tampilan sebuah halaman website.

Dengan CSS kita dapat mengatur warna, ukuran tulisan, jarak, posisi, background, tombol, layout, dan berbagai tampilan lainnya.

Contoh sederhana:

h1 {
    color: blue;
}

Kode tersebut membuat tulisan h1 menjadi berwarna biru.

2. Cara Menggunakan CSS

Ada beberapa cara untuk menggunakan CSS pada HTML.

Inline CSS

CSS ditulis langsung di dalam tag HTML. 

<h1 style="color: blue;">
    Halo Dunia
</h1>

Internal CSS

CSS ditulis di dalam tag <style>. 

<style>

h1 {
    color: blue;
}

</style>

External CSS

CSS ditulis di file terpisah, kemudian dihubungkan dengan HTML. 

<link rel="stylesheet" href="style.css">

Cara external CSS biasanya paling rapi untuk website yang memiliki banyak halaman.

3. Mengenal CSS Selector

Selector digunakan untuk menentukan elemen HTML mana yang ingin diberikan style.

Selector Tag

p {
    color: red;
}

Semua elemen <p> akan memiliki warna merah.

Selector Class

.judul {
    color: blue;
}

Class digunakan dengan tanda titik ..

Selector ID

#utama {
    color: green;
}

ID digunakan dengan tanda pagar #.

4. Mengatur Warna

CSS dapat digunakan untuk mengatur warna tulisan dan background.

Warna tulisan

p {
    color: blue;
}

Warna background

body {
    background-color: lightblue;
}

Menggunakan kode warna

h1 {
    color: #2563eb;
}

Kode seperti #2563eb merupakan kode warna hexadecimal.

5. Mengatur Tulisan

CSS dapat digunakan untuk mengatur jenis, ukuran, ketebalan, dan posisi tulisan.

Jenis font

body {
    font-family: Arial;
}

Ukuran tulisan

h1 {
    font-size: 40px;
}

Ketebalan tulisan

h1 {
    font-weight: bold;
}

Posisi tulisan

h1 {
    text-align: center;
}

6. Mengenal Box Model

Setiap elemen HTML dapat dianggap seperti sebuah kotak. CSS memiliki beberapa bagian penting dalam box model. 

.kotak {

    width: 300px;

    padding: 20px;

    border: 2px solid black;

    margin: 20px;

}

Bagian Box Model

  • Width = menentukan lebar.
  • Padding = jarak antara isi dan border.
  • Border = garis pembatas.
  • Margin = jarak dengan elemen lain.

7. Width dan Height

Width digunakan untuk menentukan lebar elemen. 

.kotak {
    width: 300px;
}

Height digunakan untuk menentukan tinggi elemen. 

.kotak {
    height: 200px;
}

8. Border dan Border Radius

Border digunakan untuk memberikan garis pada sebuah elemen. 

.kotak {
    border: 2px solid blue;
}

Border-radius digunakan untuk membuat sudut menjadi melengkung. 

.kotak {
    border-radius: 10px;
}

9. Membuat Tombol dengan CSS

CSS dapat digunakan untuk membuat tombol terlihat lebih menarik. 

button {

    background-color: #2563eb;

    color: white;

    padding: 10px 20px;

    border: none;

    border-radius: 8px;

    cursor: pointer;

}

Properti cursor: pointer membuat kursor berubah menjadi bentuk tangan ketika diarahkan ke tombol.

10. Mengenal Hover

Pseudo-class :hover digunakan untuk memberikan perubahan ketika mouse diarahkan ke sebuah elemen. 

button:hover {

    background-color: #1d4ed8;

}

11. Mengenal Flexbox

Flexbox digunakan untuk mengatur posisi beberapa elemen dengan lebih mudah. 

.container {

    display: flex;

    justify-content: center;

    align-items: center;

}

Beberapa properti penting:

  • display: flex mengaktifkan Flexbox.
  • justify-content mengatur posisi secara horizontal.
  • align-items mengatur posisi secara vertikal.
  • gap mengatur jarak antar elemen.

12. Mengenal CSS Grid

CSS Grid digunakan untuk membuat layout berbentuk baris dan kolom. 

.container {

    display: grid;

    grid-template-columns:
    repeat(3, 1fr);

    gap: 20px;

}

13. Membuat Website Responsive

Website responsive adalah website yang dapat menyesuaikan tampilannya dengan ukuran layar.

Contohnya adalah menggunakan media query. 

@media (max-width: 768px) {

    h1 {
        font-size: 30px;
    }

}

Kode tersebut akan mengubah ukuran tulisan ketika lebar layar mencapai 768px atau lebih kecil.

14. Contoh Website Sederhana

Berikut contoh sederhana penggunaan HTML dan CSS secara bersamaan.

HTML

<div class="kartu">

    <h2>PatriaTech</h2>

    <p>
        Belajar coding dari dasar.
    </p>

    <button>
        Mulai Belajar
    </button>

</div>

CSS

.kartu {

    background: white;

    width: 300px;

    padding: 25px;

    border-radius: 12px;

    text-align: center;

    box-shadow:
    0 5px 20px
    rgba(0, 0, 0, 0.1);

}

.kartu button {

    background: #2563eb;

    color: white;

    border: none;

    padding: 10px 20px;

    border-radius: 8px;

}

Kesimpulan

HTML digunakan untuk membuat struktur website, sedangkan CSS digunakan untuk mengatur tampilannya.

Setelah memahami HTML dan CSS, langkah berikutnya adalah belajar JavaScript agar website dapat menjadi lebih interaktif.
