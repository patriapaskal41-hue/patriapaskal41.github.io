Mengenal website modern dan teknologi yang digunakan untuk membuat website yang menarik dan interaktif.

1. Apa Itu Website Modern?

Website modern adalah website yang dibuat dengan memperhatikan tampilan, kenyamanan pengguna, kecepatan, keamanan, dan kemampuan beradaptasi dengan berbagai perangkat.

Website modern tidak hanya menampilkan tulisan dan gambar. Website modern biasanya memiliki tampilan yang rapi, responsif, interaktif, dan mudah digunakan.

Contoh website modern:

  • Website perusahaan
  • Website portfolio
  • Website toko online
  • Website pembelajaran
  • Website berita

2. Ciri-Ciri Website Modern

Website modern memiliki beberapa karakteristik yang membuatnya lebih nyaman digunakan oleh pengunjung.

Responsif

Website responsif adalah website yang dapat menyesuaikan tampilannya dengan ukuran layar perangkat.

  • Komputer
  • Laptop
  • Tablet
  • Smartphone

Tampilan Rapi

Website modern biasanya memiliki desain yang sederhana, terstruktur, dan nyaman dilihat oleh pengguna.

Memiliki Kecepatan yang Baik

Website modern harus berusaha memiliki waktu loading yang cepat agar pengguna tidak perlu menunggu terlalu lama.

Interaktif

Website modern dapat memberikan respons ketika pengguna melakukan suatu tindakan.

  • Tombol dapat diklik
  • Menu dapat dibuka dan ditutup
  • Form dapat memberikan pesan
  • Konten dapat berubah
  • Animasi dapat digunakan

Aman

Keamanan juga menjadi bagian penting dari website modern. Website harus berusaha melindungi data dan informasi pengguna.

3. Teknologi Dasar Website Modern

Ada tiga teknologi dasar yang perlu dipahami ketika belajar membuat website.

HTML

HTML digunakan untuk membuat struktur sebuah website. 

<h1>Selamat Datang</h1>

<p>
    Ini adalah website modern.
</p>

<button>
    Klik Saya
</button>

HTML menentukan elemen apa saja yang terdapat pada halaman website.

CSS

CSS digunakan untuk mengatur tampilan website. 

body {

    font-family: Arial, sans-serif;

    background-color: #f4f7fb;

}

button {

    padding: 10px 20px;

    border: none;

    border-radius: 8px;

}

CSS dapat digunakan untuk mengatur warna, ukuran, posisi, jarak, bentuk, animasi, dan responsivitas.

JavaScript

JavaScript digunakan untuk membuat website menjadi lebih interaktif. 

function tampilkanPesan() {

    alert("Halo! Selamat datang di website saya.");

}

Fungsi tersebut dapat dijalankan ketika pengguna menekan sebuah tombol. 

<button onclick="tampilkanPesan()">

    Klik Saya

</button>

5. Bagaimana HTML, CSS, dan JavaScript Bekerja?

Ketiga teknologi tersebut memiliki tugas yang berbeda dalam pembuatan website.

HTML = Struktur

HTML menentukan isi dan struktur website. 

<h1>PatriaTech</h1>

<p>
    Belajar membuat website.
</p>

CSS = Tampilan

CSS menentukan bagaimana website terlihat. 

h1 {

    color: #2563eb;

    text-align: center;

}

JavaScript = Interaksi

JavaScript membuat website dapat merespons tindakan pengguna. 

button.onclick = function() {

    alert("Tombol diklik!");

};

Kesimpulan

Website modern adalah website yang memperhatikan tampilan, kenyamanan pengguna, responsivitas, kecepatan, interaksi, dan keamanan.

Untuk mulai membuat website modern, kamu perlu memahami tiga teknologi utama:

  • HTML untuk membuat struktur.
  • CSS untuk membuat tampilan.
  • JavaScript untuk membuat interaksi.
